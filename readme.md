picos will send data in the format:

pico ID | user ID|

pics expect

pico ID | user ID | Name | points | streak score | special message


database setup:

User:
uid: string, primary key
name: string, optional
first_name: string, optional
last_name: string, optional
campus_id: string, optional
royalties: list[string], optional
year: int, optional
inside: boolean
tap_data: {
  total_taps: int, optional
  year_taps: int, optional
  current_streak: {
    streak_start: datetime, optional
    last_tap_at: datetime
    last_tap_day: datetime
    streak_points: int, optional
    streak_days: int, optional
    semester: string, optional
  }

  past_streak: {
    streak_start: datetime
    streak_points: int
    streak_days: int
    semester: string
  }, optional
}

MQTTClients:
uid: string, primary_key
direction: boolean
capabilities: List[str]

TapEvents:
uid: primary_key generated by postgres
mqtt_reader_uid: linked to mqtt clients
direction
uid: linked to User
